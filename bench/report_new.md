## 新任务说明（T6-T9）

| 任务 | 内容 | 考察点 |
|---|---|---|
| T6 | 100k 节点链表：malloc/new/Box 逐节点建链、遍历求和、逐个释放 | struct + 指针 + 堆分配 |
| T7 | 3000 token 字符串拼接、split、find、长度统计 | 字符串操作（值语义拷贝） |
| T8 | 泛型 struct Box<T> + 泛型函数 pick，450k 次构造/比较 | 泛型单态化 + struct 构造 |
| T9 | 1M 元素列表：move 免克隆求和 + 30 次深拷贝求和 | 所有权 move vs 值语义拷贝 |

### 语义对齐备注

- T9 python 无 move/拷贝语义：s1 按引用（无拷贝）、s2 用 `list(ys)` 显式拷贝，与 zfy `copy`、C++ 按值、Rust `clone` 对应
- T6 Rust 用 `Option<Box<Node>>` 安全链表 + 迭代式 drop；C++/zfy 手动 new/delete(malloc/free)
- zfy 自动窄化已收窄为显式 cast（new2.md #5），代码中 sizeof/下标处的 cast 为该规则产物
