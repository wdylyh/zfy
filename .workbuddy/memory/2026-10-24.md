   gui_font(16,0)，保证宽度测量/绘制/命中三处同字号（防上游字号状态污染
   导致点击定位错位）。逻辑级 pos_from_mx 边界测试过。
3. **全选覆盖残留**：逻辑验证 del_selection + Ctrl+A（KEY_CTRL+65） +
   多字节（"你好"6 字节）选区覆盖均正确（新增 widgets_test 1b 断言组）；
   用户观察到的"残留"最可能是事件丢失导致选区/按键时序错乱（同根因 1）。
4. **placeholder**：InputBox.ph 字段 + UI.placeholder(s) 标签 +
   app.set_placeholder(k,s)；draw 空文本时 C_SUB 灰字画提示（不可选中、
   不进 text_out）；focus 时空框也画光标+下划线。

变短不再残留旧字符（残影修复）。

## v3.22：copy/move/borrow 所有权系统完善（用户指令"把整个系统做完善"）
- **borrowed 表升级字段路径粒度**：slot -> 路径列表（string list list，每条路径 =
  字段段列表，[] = 整体）。EBorrow 登记 bpath（EVar 点路径 split / EField 链拼接；
  元素/解引用借用 = 整体）。
- **修关键 bug**：root_var 对点路径 EVar "b.a" 返回全名 → lookup_var 失败 → 字段
  借用静默不登记（借用联动全失效）。改为 split_field_path 取首段。
- **借用期赋值失效检查** check_borrow_write：写目标路径与在借路径重叠（任一整体
  或前缀关系）→ E3000；兄弟字段放行。接入 6 个写入点：SAssign EVar 变量/点路径
  字段链、下标写、元素字段写、SAssignList 序列字面量（变量 + 字段链）。
- **只读性强制**：`let T* p = borrow(x)`（显式非 const 指针类型）报错；类型省略
  `let p = borrow(x)` 自动落 const 槽（lconstp = ty TPtrC || init EBorrow）；
  SAssign 重绑定同理。
- **逃逸禁止**：`return borrow(x)` 报 E 悬垂；borrow 全局变量禁止（原有）。
- check_move_arg 保持整体粒度（move 只作用于根变量，任何借用冲突）。
- 坑①：bpath a 是路径列表，登记用 `::`（cons 一条路径）不是 `@`——类型错误信息
  "expected string" 曾误导（问题其实在 :: 的元素类型）。
- 坑②：字段写入 `b.a = v` 走 SAssign EVar 分支的 **None 子路径**（split_field_path
  字段链），不在 Some l 主路径——检查点要插对地方。
- 测试：examples/ownership_test.zfy（字段粒度借用+兄弟写放行+move revive+copy/move）
  正例全过；8 个负例两向拦截全对；回归 failures: 0。grammar §15 重写借用条目。
